# Frontier Model Capability

Interactive comparisons of selected frontier models across reasoning-effort
settings:

- capability versus benchmark cost per task;
- capability versus median end-to-end response time.

The charts use Artificial Analysis Intelligence Index data. They are model
selection aids, not universal rankings or substitutes for workload-specific
evaluation.

## Site

https://haolingdong-msft.github.io/frontier-model-capability/

## Data notes

Current model series were refreshed on October 21, 2026. GPT-5.6 Sol uses
retained September 29, 2026 data because it was absent from the refreshed
leaderboard.
