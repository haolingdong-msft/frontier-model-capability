How execution time is measured

The horizontal value is the published median end-to-end response time in seconds. It includes time before and during answer generation, making it more useful for reasoning models than output tokens per second alone. Lower is faster, so the preferred region is the upper-left.

It still does not represent full agent execution time. Repository discovery, tool calls, compilation, network retrieval, retries, and human waits are outside a standalone model response. Use this graph to compare model-serving behavior, then benchmark complete tasks in your actual workflow.

Some model-effort variants have no published end-to-end timing in the retained snapshot. They are omitted rather than estimated, and curves are not connected across missing measurements. What this research does not establish

None of these sources isolates production backend API work, this TypeSpec repository, or Chinese technical writing. Word artifact scores are not pure prose-style preferences. Arena Code and Creative Writing returned HTTP 403 in the earlier 21 Oct research, so no Arena scores or creative-writing rankings have been invented. Agent harnesses, budgets, dates, samples, and effort settings differ. Creative Writing was rechecked on 28 Oct and still returned 403. Full provenance, subcategory scores, and collection exclusions are in the downloadable task data.

Turn benchmark results into a local decision

Evaluation suggestions, not additional measured model rankings.

UI / frontend
Visuals + working interactions

Use website preferences to shortlist visual candidates. Then check responsive layouts, accessibility, interaction behavior, and changes in the real codebase.

Backend / engineering
Executable acceptance criteria

Keep the agent, tools, repository, and budget comparable. Measure tests passed, API behavior, regressions, retries, total cost, and full task wall time.

Documents / writing
Evidence + editorial quality

Check facts and citations, requirement coverage, audience fit, clarity, and formatting. Business-artifact benchmarks do not replace a review of your actual documents.

For assessment-skill: Keep compilation, evidence extraction, validation, and rendering in code. Use a stronger model for the hard design and compatibility judgments, then a cheaper model for bounded implementation. A failed cheap attempt plus retries can cost more than one successful stronger attempt.
