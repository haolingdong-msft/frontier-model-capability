How to read the picture

Upper-left is better: more measured capability for less money. Each color is a model; points 1 to 5 are low, medium, high, xhigh, and max. The cost axis is logarithmic because the measured costs span more than 1,000x. These are average evaluation costs per task, not a quote for your task or Copilot AIC.

Price per token is not cost per task. Sonnet max has a lower token rate than Opus max, but uses enough tokens that its benchmark cost is higher: $5.46 / 56.0 versus $5.98 / 57.6. That is why plotting only token rates would give the wrong picture.

More effort is not always the best purchase. Opus medium measures $1.34 / 51.2; Astra high measures $1.73 / 50.9. Their score difference is too small to treat as decisive, but their benchmark costs differ. GPT-6.1 Sol high measures $0.32 / 50.2, versus Gemini high at $1.24 / 40.9. Those are observations on this suite, not universal task rankings.

Important limits

The Intelligence Index v4.3.2 mixes agent tasks, coding, scientific reasoning, and general tasks; it is not an IQ score or a TypeSpec accuracy measure. This picture covers seven selected model families, not every available model. Lines do not interpolate unmeasured settings. Gemini low has a score but no published cost in the extracted data; its xhigh/max settings are unsupported. Claude entries use adaptive reasoning with default fallback. GPT-5.6 Sol is absent from the refreshed leaderboard, so its retained 29 Sep results are shown as historical comparison data.

No speed claim is encoded: end-to-end latency must be measured separately. Provider effort levels are not equal compute budgets. Benchmark costs use API pricing, not Copilot credits, and depend on task mix, token usage, and evaluation settings.

Final selection rule: run the same representative cases with the same tools and context. Track finding accuracy, tests, retries, total cost/AIC, and wall time. Choose the least costly configuration that passes your quality bar.

How execution time is measured

The horizontal value is the published median end-to-end response time in seconds. It includes time before and during answer generation, making it more useful for reasoning models than output tokens per second alone. Lower is faster, so the preferred region is the upper-left.

It still does not represent full agent execution time. Repository discovery, tool calls, compilation, network retrieval, retries, and human waits are outside a standalone model response. Use this graph to compare model-serving behavior, then benchmark complete tasks in your actual workflow.

Some model-effort variants have no published end-to-end timing in the retained snapshot. They are omitted rather than estimated, and curves are not connected across missing measurements.
