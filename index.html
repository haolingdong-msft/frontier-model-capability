How to read the picture

Upper-left is better: more measured capability for less money. Each color is a model; points 1 to 5 are low, medium, high, xhigh, and max. The cost axis is logarithmic because the measured costs span more than 1,000x. These are average evaluation costs per task, not a quote for your task or Copilot AIC.

Price per token is not cost per task. Benchmark cost reflects both token prices and tokens consumed. Sonnet max measures $5.46 / 56.0; Opus max measures $5.98 / 57.6 (cost / capability score). Token rates alone cannot tell you the total cost of completing a task.

More effort is not always the best purchase. Use the task-specific evidence below to form a shortlist, then compare settings on your own cases. A small difference in the aggregate score does not establish a frontend, backend, or writing advantage.

How execution time is measured

The horizontal value is the published median end-to-end response time in seconds. It includes time before and during answer generation, making it more useful for reasoning models than output tokens per second alone. Lower is faster, so the preferred region is the upper-left.

It still does not represent full agent execution time. Repository discovery, tool calls, compilation, network retrieval, retries, and human waits are outside a standalone model response. Use this graph to compare model-serving behavior, then benchmark complete tasks in your actual workflow.

Some model-effort variants have no published end-to-end timing in the retained snapshot. They are omitted rather than estimated, and curves are not connected across missing measurements.

What this research does not establish

None of these sources isolates production backend API work, this TypeSpec repository, or Chinese technical writing. Word artifact scores are not pure prose-style preferences. Arena Code and Creative Writing returned HTTP 403 during retrieval, so no Arena scores or creative-writing rankings have been invented. Agent harnesses, budgets, dates, samples, and effort settings differ. Full provenance is in the downloadable task data.

Turn benchmark results into a local decision

Evaluation suggestions, not additional measured model rankings.

UI / frontend
Visuals + working interactions

Use website preferences to shortlist visual candidates. Then check responsive layouts, accessibility, interaction behavior, and changes in the real codebase.

Backend / engineering
Executable acceptance criteria

Keep the agent, tools, repository, and budget comparable. Measure tests passed, API behavior, regressions, retries, total cost, and full task wall time.

Documents / writing
Evidence + editorial quality

Check facts and citations, requirement coverage, audience fit, clarity, and formatting. Business-artifact benchmarks do not replace a review of your actual documents.

For assessment-skill: Keep compilation, evidence extraction, validation, and rendering in code. Use a stronger model for the hard design and compatibility judgments, then a cheaper model for bounded implementation. A failed cheap attempt plus retries can cost more than one successful stronger attempt.

Important limits

The Intelligence Index v4.3.2 mixes agent tasks, coding, scientific reasoning, and general tasks; it is not an IQ score or a TypeSpec accuracy measure. This picture covers seven selected model families, not every available model. Lines do not interpolate unmeasured settings. Gemini low has a score but no published cost in the extracted data; its xhigh/max settings are unsupported. Claude entries use adaptive reasoning with default fallback. GPT-5.6 Sol is absent from the refreshed leaderboard, so its retained 29 Sep results are shown as historical comparison data.

The cost chart alone does not encode latency; response time is shown separately. Provider effort levels are not equal compute budgets. Benchmark costs use API pricing, not Copilot credits, and depend on task mix, token usage, and evaluation settings.

Final selection rule: run the same representative cases with the same tools and context. Track finding accuracy, tests, retries, total cost/AIC, and wall time. Choose the least costly configuration that passes your quality bar.
